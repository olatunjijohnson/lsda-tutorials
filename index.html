Longitudinal and Spatial Data Analysis

MATH48132 / MATH68132 — tutorial sheets

These are the weekly tutorial sheets. Every code block on this site runs in your browser — there is nothing to install to get started, and nothing you can break. Edit the code, press Run, and see what happens.

TipYou do not need R installed to use this site

The R session runs inside your browser using WebAssembly. The first code block on a page takes a few seconds to start while R downloads; after that it is immediate. Nothing is sent to a server, and nothing is saved — refreshing the page resets everything.

Working on your own machine

The browser is fine for the exercises, but for the coursework you will want R locally. Everything the course uses is in one package — see Install R packages.

install.packages("lsda", repos = c("https://olatunjijohnson.r-universe.dev",
                                   "https://cloud.r-project.org"))

Then every dataset is one call away, with documentation:

library(lsda)
data(cattle)
?cattle
